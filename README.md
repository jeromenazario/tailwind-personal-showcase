# Jerome — Personal Website
### A Personal Portfolio | Multimedia Development Activity

---

## 📌 Project Overview

This is a personal portfolio website built to showcase **who I am beyond academics**. Instead of a traditional résumé-style portfolio, this site presents a more human side — including passions, music, dream places, and life goals.

The goal of this project is to create a **visually unique and expressive digital identity** using a magazine-inspired layout while practicing front-end development skills.

---

## 🗂️ Files

| File | Description |
|---|---|
| `index.html` | Main HTML file containing the entire website (single-page layout) |

> ⚠️ This project uses CDN-based styling (Tailwind CSS & Google Fonts), so no external CSS file is included.

---

## 📄 Sections

The website is a **Single-Page Application (SPA)** — all content is displayed in one page and navigated through a fixed navbar.

1. **Hero Section** — Introduction, personal statement, and identity tags  
2. **Passions & Interests** — Machine Learning, Running, and Continuous Learning  
3. **Music (On Rotation)** — Songs that reflect current mood and personality  
4. **Dream Locations** — Places I aspire to visit or live in  
5. **Goals & Aspirations** — Personal and career-driven ambitions  
6. **Bucket List** — Life experiences I aim to achieve before 30  

---

## 🛠️ Technologies Used

- HTML5  
- CSS3 (Custom Properties, Grid, Flexbox)  
- Tailwind CSS (via CDN)  
- Google Fonts (Playfair Display, Space Mono)  
- No frameworks or libraries  

---

## 🎨 Design

- **Theme:** Editorial / Magazine-inspired layout  
- **Color Palette:** Cream, tan, rust, and dark neutrals  
- **Typography:** Playfair Display (headings) + Space Mono (body)  
- **Layout:** Responsive — works on desktop, tablet, and mobile  

---

## 🚀 How to Run

1. Download or clone the repository  
2. Open `index.html` in any web browser  

No installations or dependencies required.
